
# Security Policy

## Project Status

Rufus Terminal is an open-source personal website currently under development.

There is no stable production release yet.

Security issues will be reviewed as the project evolves.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately.

1. Open the repository's **Security** tab.
2. Navigate to **Advisories**.
3. Select **Report a vulnerability**.
4. Describe the issue and how it can be reproduced.

Please include:
- A description of the vulnerability.
- The affected files or components.
- Steps to reproduce the issue.
- The potential security impact.

Do not disclose vulnerabilities through public GitHub Issues.

Please do not include real passwords, API keys or other sensitive credentials in reports.

## Security Practices

This project aims to follow these practices:

- Keep dependencies updated.
- Use automated security scanning.
- Never commit credentials or secrets.
- Review third-party libraries.
- Apply the principle of least privilege.
- Validate changes before deployment.
- Avoid unnecessary client-side dependencies.

## Supported Versions

The project is currently in active development.

No stable release is supported yet.

## Disclosure

Please allow time for investigation and remediation before publicly disclosing a reported vulnerability.

Security fixes and updates will be documented through repository commits and release notes when applicable.
