Session prête

Ce qui se passe dans le navigateur

Le bureau conserve les fichiers texte en mémoire. Python démarre à la demande via Pyodide 0.27.5 et peut installer des paquets compatibles avec WebAssembly via micropip. JavaScript s’exécute dans un worker séparé. Aucun serveur d’exécution ni stockage des fichiers sur Cloudflare. Les téléchargements de runtime, paquets et recherches externes nécessitent Internet.

Ce n’est pas un PC x86 complet : pas de processus Linux natifs, de gestionnaire apt, d’accès aux disques de l’ordinateur ou de réseau TCP brut. Le navigateur peut mettre en cache les ressources publiques indépendamment de la session. Pour tester un véritable OS émulé, v86 est une piste distincte.
