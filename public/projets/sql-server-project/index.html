Mission SQL Cinéma

Application pédagogique et modèle relationnel de cinéma pour pratiquer les jointures, agrégations et analyses de données.

Contexte et objectif

Mission SQL Cinéma propose des défis autour des films, cinémas, séances, clients et réservations. Une interface Flask locale se connecte à Microsoft SQL Server via pyodbc. Le projet prévoit un générateur visant dix millions de réservations synthétiques.

Contenu du projet

  • Schéma relationnel destiné aux exercices de jointures et de regroupements.
  • Défis guidés portant sur les agrégations et l’analyse temporelle.
  • Scripts de préparation Windows, génération de données et contrôle des résultats.
  • Préparation d’un rôle SQL en lecture seule et tests applicatifs et d’intégration.

Ce que j’explore

Travailler sur des données réalistes tout en distinguant logique relationnelle, performance des requêtes, permissions et interface applicative.

État et limites

Dix millions de réservations est l’objectif du générateur, pas un volume de données que je prétends avoir vérifié sur une instance active.
