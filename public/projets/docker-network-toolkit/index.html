Docker Network Toolkit

Laboratoire réseau conteneurisé pour observer les communications, diagnostiquer les services et mesurer les performances.

Contexte et objectif

Une machine virtuelle Ubuntu héberge un environnement Docker Compose. Un conteneur toolbox rassemble les commandes de diagnostic, un serveur Nginx fournit un service HTTP et un serveur iperf3 sert à mesurer le débit. Les services communiquent par un réseau bridge.

Contenu du projet

  • Création d’images Docker personnalisées et déploiement des trois services.
  • Tests de résolution DNS, de connectivité ICMP et d’accès HTTP entre conteneurs.
  • Observation des ports TCP avec Nmap et mesures de débit avec iperf3.
  • Documentation des commandes et automatisation des vérifications avec Bash.

Ce que j’explore

Distinguer les ports internes des ports publiés, comprendre la résolution par nom de service et observer l’isolation d’un réseau Docker.

État et limites

Les vérifications principales sont rapportées dans le dépôt. Elles concernent le laboratoire décrit, pas toutes les configurations Docker ni un audit indépendant.
