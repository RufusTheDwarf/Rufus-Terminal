Terminal

Mon espace personnel : projets, journal, jeux, applications et atelier de programmation dans le navigateur.

Contexte et objectif

Terminal rassemble mes projets, mes activités et mes découvertes. Le site propose un journal personnel distinct du journal technique, ainsi qu’un atelier expérimental.

Contenu du projet

  • Pages HTML statiques accessibles sans JavaScript.
  • Terminal de navigation et filtres de catalogue côté navigateur.
  • Métadonnées spécifiques à chaque page, sitemap et liens internes.
  • Publication statique avec Cloudflare Workers et génération reproductible des pages.
  • Thèmes Retro Glass et Sage Day avec préférence locale.
  • Contrôle périodique des écarts entre le catalogue et les dépôts publics GitHub.
  • Atelier expérimental avec fichiers texte temporaires, éditeur et exécution JavaScript; Python via Pyodide à vérifier en production.

Ce que j’explore

Concilier une identité visuelle originale avec la maintenabilité, l’accessibilité, les performances et la découvrabilité du contenu.

État et limites

Le catalogue est éditorial. La détection automatique signale les nouveaux dépôts et les écarts. Les mises à jour publiques sont relues et signées avant publication.

Code et documentation

Le dépôt GitHub rassemble la documentation et les fichiers disponibles. Consulte les instructions, les versions et les conditions de licence propres à ce projet.
