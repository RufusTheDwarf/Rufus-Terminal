Git Signed Commits Windows

Guide Windows pour créer une identité de signature SSH dédiée et vérifier les signatures Git et GitHub.

Contexte et objectif

Ce guide distingue une clé d’authentification SSH d’une clé de signature. Il documente la création d’une clé dédiée, la configuration de Git, l’enregistrement de la clé publique sur GitHub et la vérification locale des commits.

Contenu du projet

  • Génération d’une paire de clés Ed25519 dédiée à la signature.
  • Configuration de Git pour signer automatiquement les nouveaux commits.
  • Gestion du fichier allowed_signers pour vérifier les signatures localement.
  • Contrôle du statut GitHub et protection de la clé privée.

Ce que j’explore

La signature cryptographique associe le contenu d’un commit à une identité de signature. Elle ne prouve pas à elle seule la qualité ou l’innocuité du code signé.

État et limites

La validation locale et le statut Verified affiché par GitHub sont deux vérifications distinctes. La clé privée ne doit jamais être publiée.

Code et documentation
