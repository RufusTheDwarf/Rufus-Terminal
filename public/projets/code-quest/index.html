Code Quest

RPG en terminal où les connaissances informatiques deviennent une mécanique de combat et de progression.

Contexte et objectif

Code Quest associe questions techniques et affrontements contre des ennemis inspirés des erreurs de programmation et des concepts de cybersécurité. Les bonnes réponses permettent d’avancer, de gagner de l’expérience et d’accéder aux défis suivants.

Contenu du projet

  • Combat basé sur des questions à choix multiples.
  • Expérience, niveaux, santé et quatre niveaux de difficulté.
  • Sprites ASCII, défis bonus et progression de difficulté persistante.

Ce que j’explore

Explorer la pédagogie par le jeu : associer les objectifs d’apprentissage à des choix, des retours immédiats et une progression lisible.

État et limites

Le jeu ne remplace pas une formation complète en informatique. Les téléchargements et versions disponibles sont à vérifier sur le dépôt.

Code et documentation

Le dépôt GitHub rassemble la documentation et les fichiers disponibles. Consulte les instructions, les versions et les conditions de licence propres à ce projet.
