Cloud Project K3s

Conception d’un mini cloud privé à deux nœuds pour héberger une application de gestion des demandes d’assistance.

Contexte et objectif

Ce laboratoire pédagogique explore le cycle de vie d’un service dans un cluster Kubernetes léger. Deux machines virtuelles Ubuntu Server jouent les rôles de serveur et d’agent K3s. Le projet associe une application Helpdesk et une base PostgreSQL pour étudier le déploiement et l’exploitation de services internes.

Contenu du projet

  • Préparation des machines virtuelles et installation des deux rôles K3s.
  • Définition des workloads, Services, volumes persistants et droits RBAC.
  • Procédures de mise à jour, retour arrière, sauvegarde et restauration de PostgreSQL.

Ce que j’explore

Comprendre la différence entre orchestration, réseau, stockage et exploitation : un Pod peut être remplacé sans que les données persistantes soient nécessairement perdues.

État et limites

Le projet est en cours de réalisation. Les procédures et manifestes ne constituent pas une garantie de déploiement complet ni une infrastructure prête pour la production.
